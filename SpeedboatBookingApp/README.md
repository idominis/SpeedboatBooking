# Speedboat Booking Application

A speedboat transfer booking system built with .NET 6, featuring a RESTful API backend and a Blazor WebAssembly frontend.

## Project Structure

The solution consists of two main projects:

- **SpeedboatBookingApi** - ASP.NET Core Web API (.NET 6) with Swagger/OpenAPI support
- **SpeedboatBookingApp** - Blazor WebAssembly client application (.NET 6)

## Prerequisites

- [.NET 6 SDK](https://dotnet.microsoft.com/download/dotnet/6.0)
- Visual Studio 2022 or Visual Studio Code
- Google Sheets API credentials (JSON file)
